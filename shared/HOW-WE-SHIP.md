Актуально с **31.08.2026** (вечерний канон). Канал: dzen.ru/artur_horosheff.
Автоматизация: репо `vgmixailoff/exmashin`. Публикация только через

## Стоимость (HARD)

**Один** cloud-агент (Директор) на весь выпуск. Роли = `Task` в том же ране.
`/in-cloud` **запрещён**. Хранилище канона — **git origin/main**, не GitHub PR.
См. `CLOUD-AUTOMATION.md`, `shared/cloud-cost-rules.md`, `shared/cursor-subagents.md`.

## Модели

| Что | Кто |
|-----|-----|
| Директор и роли, кроме Writer | Grok 4.7 Medium, Fast выключен (`grok-4.7-medium`) |
| Факты / ресерч | Агент Research на Grok 4.7 Medium (англ. склад ок) |
| Весь русский текст для людей | **Gemini 3.8 Flash** (`gemini-3.8-flash`) |
| Обложка 16:9 | Kie **GPT Image 2** t2i (1K) — единственный генератор; нет `KIE_API_KEY` → BLOCKER. См. `shared/cover-generator-decision.md` |
| Картинки в тексте | Inline Visuals: официальный скрин или одна AI-схема; при ошибке надписей — точный PIL-рендер |

**Важно:** выбранная chat-модель (Gemini) сама картинку не рисует —
генерация идёт через Kie GPT Image 2. Встроенный Cursor `GenerateImage`
(Nano Banana Pro) не используем: нет гарантированного 16:9 и точного
логотипа (доказательно: `shared/cover-generator-decision.md`).

Sol / Тележенька / Лебедев **не** переписывают финал. Имени Лебедева в
тексте нет.

## Шаги выпуска

```text
Scout? → research_start → Research
→ Gemini (один JSON: TITLE/DESCRIPTION/BODY/COVER_*/INLINE_*)
→ materialize + gemini_article_gate
→ stamp + html_linter
→ Cover (отдельная обложка) ‖ Schema
→ Inline Visuals (официальные скрины и нужная схема внутри текста)
→ Indexer → Publish (WP) → Content-learner → Fixer? → merge → titles → purge
```

## Картинки по смыслу

Обложка — Kie GPT Image 2.5 Sunburst i2i: комикс с маскотом, TITLE только в промпте.  
Остальное делает отдельный Inline Visuals: (A) официальные скрины браузером
с доков продукта, рядом с объяснением и с подписью; (B) максимум одна
AI-схема из `INLINE*_ONIMAGE`, если помогает новичку. Стиль — белый лист,
чёрные рукописные линии. Ошибки букв/цифр в AI-картинке → точный локальный
рендер без второго платного вызова.
Количество инлайнов не задано заранее.
`cover.png` — герой сайта (featured) + RSS enclosure в Дзен, не дубль в теле. Подробно:
`shared/article-images-contract.md`.
